2. Conferma la sostituzione dei file.
3. GitHub Desktop: Commit to main -> Push origin.
4. Esegui Actions -> CI.
5. Se verde, Actions -> Build distributables.
6. Scarica LyriCar-standard-unsigned-IPA.

Comportamento:
- Con timestamp della riga corrente + timestamp della riga successiva: illuminazione karaoke progressiva.
- Senza timestamp successivo affidabile: renderer invariato, senza karaoke artificiale.
- Seek/pausa/ripresa seguono lo stesso clock monotono della barra e dei lyrics.
