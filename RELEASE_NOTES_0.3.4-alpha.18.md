# LyriCar 0.3.4-alpha.18 — Single Lyrics Widget

Questa build riduce i widget lyrics della build standard da tre a uno.

## Nuovo layout

Il widget `LyriCar · Lyrics` mostra esclusivamente:

- riga precedente — grigio;
- riga attuale — bianco, più grande e più evidente;
- riga successiva — grigio.

I vecchi widget `LyriCar · Superiore`, `LyriCar · Corrente` e `LyriCar · Dopo` non vengono più esposti dal WidgetBundle.

La Live Activity CarPlay usa lo stesso schema a tre righe per mantenere coerente la prova su CarPlay.

Spotify originale rimane separato e non viene modificato.
